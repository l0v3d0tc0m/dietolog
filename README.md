# health-agent

Личный ассистент по питанию: данные с Redmi Watch и FatSecret попадают через Health Connect на ПК, а Claude в Telegram знает, сколько ты съел, сколько потратил, что лежит в холодильнике, и советует, что доесть.

```
Redmi Watch → Mi Fitness ─┐
FatSecret ────────────────┴→ Health Connect → Android-приложение HealthSync
                                                   │  POST /ingest (каждые 30 мин)
                                                   ▼
                                ПК: python -m app.main  (SQLite в data/health.db)
                                                   │
                                     Claude + инструменты ⇄ Telegram-бот
```

## Запуск на ПК

1. Создай бота у [@BotFather](https://t.me/BotFather), а свой числовой id узнай у [@userinfobot](https://t.me/userinfobot).
2. Выбери, на чём работает агент:
   - **Подписка Claude, без ключа API** (`AGENT_BACKEND=claude_code`). Выполни один раз в терминале `claude setup-token`, войди в браузере и вставь полученный токен в `CLAUDE_CODE_OAUTH_TOKEN` в `.env`. Если `claude` не в PATH, бот сам найдёт копию из десктопного приложения Claude; путь можно задать и вручную через `CLAUDE_BIN`. Запросы расходуют лимиты подписки, а ответ приходит медленнее, чем через API (примерно 10–30 секунд).
   - **Ключ API** (`AGENT_BACKEND=api`): возьми ключ на https://platform.claude.com и впиши его в `ANTHROPIC_API_KEY`.
3. Заполни `.env`: `INGEST_TOKEN` уже сгенерирован, остальное впиши сам.
4. Запусти бота двойным кликом по `run-bot.cmd` или командой:

```bash
.venv/Scripts/python -m app.main
```

Если Windows спросит про брандмауэр, разреши доступ в частных сетях, иначе телефон не достучится.

Чтобы развернуть проект заново: `py -3.14 -m venv .venv`, затем `.venv/Scripts/pip install -r requirements.txt`.

## Попробовать без телефона

Создай базу с двумя неделями выдуманных данных (активность, сон, еда, холодильник):

```bash
.venv/Scripts/python -m app.demo
```

Дальше выбери один из вариантов:
- **чат в терминале**, нужен только `ANTHROPIC_API_KEY`:
  ```bash
  .venv/Scripts/python -m app.cli --demo
  ```
- **полный бот в Telegram на демо-базе**: поставь `DB_PATH=data/demo.db` в `.env` и запусти как обычно. Потом не забудь вернуть `data/health.db`.

## Телефон

1. Собери APK: запусти двойным кликом `android/build-apk.cmd`. Он берёт JDK 21, Android SDK и Gradle 9.6.0 из папки `.tools/` в корне проекта, они уже лежат там. Готовый файл появится в `HealthSync.apk` в корне проекта, лог сборки — в `android/build-log.txt`. Скинь APK на телефон и установи (Android попросит разрешить установку из этого источника). Можно и через Android Studio: открой папку `android/` и нажми Run ▶.
2. В Mi Fitness и FatSecret включи запись в Health Connect.
3. В приложении HealthSync:
   - адрес: `http://<IP ПК>:8765`. IP смотри через `ipconfig` (IPv4 в Wi-Fi). С [Tailscale](https://tailscale.com) подставь IP вида `100.x.x.x`, тогда синхронизация работает и вне дома;
   - токен: `INGEST_TOKEN` из `.env`;
   - нажми «Разрешения Health Connect», выдай всё, включая чтение в фоне;
   - нажми «Синхронизировать сейчас». Внизу должно появиться `OK: …`.

Дальше телефон сам отправляет данные за последние 7 дней примерно раз в 30 минут, когда есть сеть.

## Первое сообщение боту

Напиши, например: «мужчина, 10.05.1998, рост 180, вес 82, хочу худеть с дефицитом 400». Агент заполнит профиль. После этого:

- `/today`, `/yesterday`, `/week` — быстрые сводки, без Claude и бесплатно;
- «сколько мне ещё можно съесть?», «что поесть на ужин?»;
- «купил 1 кг куриного филе, 10 яиц, 2 кг гречки»;
- «сварил плов из 500 г курицы и 300 г риса, вышло 4 порции»;
- фото холодильника или чека;
- «не люблю рыбу», «аллергия на орехи» — запомнит.

Каждое утро в 9:00 бот присылает итоги вчерашнего дня (`MORNING_REPORT_HOUR` в `.env`, `-1` выключает).

## Как считается норма

- Базовый обмен по формуле Миффлина — Сан Жеора × 1.1 (переваривание и бытовые движения).
- Плюс активные калории с часов × `active_kcal_factor` (по умолчанию 0.85, потому что часы завышают).
- Плюс цель `goal_kcal_delta` (−400 = дефицит).
- Белок 1.8 г/кг, жир 0.9 г/кг, остальное углеводы.

Все коэффициенты хранятся в профиле, их можно поменять, просто попросив бота. Логика лежит в `app/nutrition.py`.

## Файлы

| Файл | Что делает |
|---|---|
| `app/main.py` | запускает сервер и бота |
| `app/ingest.py` | принимает данные с телефона |
| `app/db.py` | схема SQLite |
| `app/nutrition.py` | расчёт нормы и баланса |
| `app/tools.py` | инструменты агента (дневник, холодильник, профиль, предпочтения) |
| `app/agent.py` | цикл Claude через API и системный промпт |
| `app/agent_cc.py` | агент через Claude Code (`claude -p`) на подписке |
| `app/mcp_server.py` | MCP-сервер, через который Claude Code получает инструменты |
| `app/bot.py` | Telegram-бот и утренний отчёт |
| `app/cli.py` | чат с агентом в терминале |
| `app/demo.py` | генератор демо-данных |
| `tests/` | тесты |
| `android/` | приложение HealthSync для Health Connect |

## Стоимость

По умолчанию используется `claude-opus-5-5` с `CLAUDE_EFFORT=medium`. Это примерно несколько центов за сообщение, точнее видно в консоли Claude. Если хочется дешевле, поставь `CLAUDE_EFFORT=low` или `CLAUDE_MODEL=claude-haiku-5-5`.
